# Локальный агент для ПК и кода

Claude Code-inspired интерфейс для существующего локального агента на Python. Ассистент понимает обычные просьбы: например, «измени проект», «скачай файл по ссылке» или «напиши @username в Telegram». Для короткой неоднозначной команды он должен запросить недостающие данные, а не угадывать.

## Запуск

1. Установи Python 3.10+ и Ollama.
2. Скачай в Ollama модель, поддерживающую вызов инструментов (tool calling), затем проверь её командой `ollama list`. Доступные модели можно выбрать в списке в окне.
3. Запусти из папки проекта:

   ```bash
   python claude_style.py
   ```

Запуск через `python ai_assistant.py` по-прежнему доступен.

## Как пользоваться

- Выбери папку проекта сверху. Включённый по умолчанию режим «Агент» позволяет написать задачу обычным текстом: агент читает файлы, планирует изменения, редактирует их и проверяет результат.
- Для распространённых задач нажми одну из подсказок над чатом и замени текст в `<скобках>`.
- «Весь ПК» выключен по умолчанию: сначала агент ограничен папкой проекта. Включай доступ к остальным папкам только если он действительно нужен.
- Перед отправкой Telegram-сообщений, скачиванием файлов и потенциально рискованными изменениями программа запрашивает подтверждение. Перед действием проверь получателя, URL, путь и содержание.
- `Ctrl+L` переводит курсор в поле ввода, `Ctrl+Enter` отправляет запрос, `/undo` отменяет последнюю правку, `/clear` очищает историю.

## Важно

Это не официальный продукт Anthropic и не использует облачную модель Claude: интерфейс вдохновлён Claude Code, а ответы и инструменты работают через локальную Ollama. Для скачивания и отправки сообщений агенту нужны конкретные данные (ссылка/имя получателя и текст). Не отключай подтверждения для действий, которые могут отправить сообщение или изменить файлы.
